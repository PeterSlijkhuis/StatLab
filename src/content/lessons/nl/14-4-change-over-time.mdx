## Een groep-bij-tijd-interactie

Tijd varieert **binnen** werknemers en training varieert **tussen** hen. Een ontwerp met beide
heet vaak een gemengd ontwerp, of een split-plot-ontwerp. De vraag "verschilde de verandering
tussen groepen?" is een interactie, precies zoals in Module 13.

<CodeBlock id="c-mixed" code={`m_mixed <- lmer(engagement ~ time * training + (1 | employee_id), data = long_d)

coef(summary(m_mixed))`} />

Lees de vier vaste effecten zoals in Module 13:

- **`(Intercept)`**: de ongetrainde groep op t1.
- **`timet2`**: de verandering voor de ongetrainde groep.
- **`trainingYes`**: hoeveel hoger de getrainde groep op t1 zat dan de ongetrainde.
- **`timet2:trainingYes`**: hoeveel **meer** de getrainde groep veranderde. Dit is het
  antwoord op de onderzoeksvraag.

## Drie metingen: voor, midden, na

De werkplekdata hebben twee metingen. Voor drie is hier een kleine gesimuleerde studie: 60
werknemers beoordelen hun stress voor een programma, halverwege en erna.

<CodeBlock id="c-waves" code={`set.seed(114)
n <- 60
id <- factor(1:n)
base <- rnorm(n, 30, 6)
wide <- data.frame(
  id,
  pre = round(base + rnorm(n, 0, 3), 1),
  mid = round(base - 3 + rnorm(n, 0, 3), 1),
  post = round(base - 5 + rnorm(n, 0, 3), 1)
)

waves <- wide %>%
  pivot_longer(cols = c(pre, mid, post), names_to = "wave", values_to = "stress") %>%
  mutate(wave = factor(wave, levels = c("pre", "mid", "post")))

waves %>%
  group_by(wave) %>%
  summarise(mean_stress = mean(stress), sd_stress = sd(stress))`} />

Er zijn twee manieren om tijd in het model te zetten, en ze beantwoorden verschillende
vragen.

<CodeBlock id="c-factor" code={`m_waves <- lmer(stress ~ wave + (1 | id), data = waves)
coef(summary(m_waves))
anova(m_waves)`} />

**Tijd als factor** geeft elke meting zijn eigen gemiddelde: twee dummyvariabelen, vergeleken
met de voormeting. De *F*-toets vraagt of de drie gemiddelden verschillen.

<CodeBlock id="c-linear" code={`waves <- waves %>% mutate(wave_number = as.numeric(wave) - 1)

m_linear <- lmer(stress ~ wave_number + (1 | id), data = waves)
coef(summary(m_linear))`} />

**Tijd als getal** (0, 1, 2) past één rechte lijn aan: één helling, de gemiddelde verandering
per meting. Hier is dat ongeveer −2,35 punten stress per meting. Het kost één vrijheidsgraad
in plaats van twee, wat power oplevert wanneer de verandering echt gelijkmatig is, en het
misleidt wanneer ze dat niet is, bijvoorbeeld wanneer alles tussen voor en midden gebeurt.
