Het lineaire model van Deel 3 heeft een Bayesiaanse versie met dezelfde formule. Het verschil
zit in wat eruit komt: geen schatting met een p-waarde, maar een posteriorverdeling voor elke
coëfficiënt, met een prior die je bewust kiest.

## De helling als onbekende

Neem het model van welzijn op autonomie uit Les 10-2.

<CodeBlock id="c-lm" code={`d <- read.csv("data/workplace.csv", stringsAsFactors = TRUE)

m_autonomy <- lm(wellbeing ~ autonomy, data = d)
summary(m_autonomy)$coefficients

b_hat <- coef(m_autonomy)[["autonomy"]]
se_hat <- summary(m_autonomy)$coefficients["autonomy", "Std. Error"]
c(b_hat = b_hat, se_hat = se_hat)`} />

De helling is nu de onbekende, zoals het vertrekpercentage dat in Les 16-1 was. Bij een paar
honderd gevallen wordt wat de data erover zeggen heel goed samengevat door een normale curve
gecentreerd op de schatting, met de standaardfout als spreiding. Die curve is de likelihood,
dus de rastermethode werkt precies als eerder.

<CodeBlock id="c-flat" code={`b_grid <- seq(-1, 3, length.out = 4001)

prior_flat <- rep(1, length(b_grid))
likelihood <- dnorm(b_hat, mean = b_grid, sd = se_hat)

post_flat <- prior_flat * likelihood
post_flat <- post_flat / sum(post_flat)

# Posterior mean, and a 95% credible interval read off the grid.
sum(b_grid * post_flat)
cdf <- cumsum(post_flat)
c(b_grid[which(cdf >= 0.025)[1]], b_grid[which(cdf >= 0.975)[1]])

confint(m_autonomy)["autonomy", ]`} />

Met een vlakke prior is het posterior gemiddelde de kleinste-kwadratenschatting en komt het
geloofwaardigheidsinterval op twee decimalen overeen met het betrouwbaarheidsinterval. Dat is
goed om te weten: **een Bayesiaanse regressie met vlakke prior geeft de getallen die je al
kent, met de Bayesiaanse lezing erbij.**

## De snelkoppeling: een gewogen gemiddelde

Wanneer zowel de prior als de likelihood normale curves zijn, is de posterior ook een normale
curve, en is geen raster nodig. Elke bron wordt gewogen naar zijn **precisie**, één gedeeld
door zijn variantie.

<CodeBlock id="c-formula" code={`prior_sd <- 0.5
w_data <- 1 / se_hat^2
w_prior <- 1 / prior_sd^2

post_mean <- (w_data * b_hat + w_prior * 0) / (w_data + w_prior)
post_sd <- sqrt(1 / (w_data + w_prior))
c(post_mean = post_mean, post_sd = post_sd)

# A 95% credible interval, and the probability of two claims.
qnorm(c(0.025, 0.975), mean = post_mean, sd = post_sd)
pnorm(0, mean = post_mean, sd = post_sd, lower.tail = FALSE)
pnorm(0.5, mean = post_mean, sd = post_sd, lower.tail = FALSE)`} />

De data wegen ongeveer 22 tegen 4 van de prior, en daarom domineren ze. De laatste twee regels
zijn het soort antwoord waarvoor een Bayesiaanse regressie dient: het is vrijwel zeker dat de
helling positief is, en er is ongeveer 98% kans dat ze boven een half punt ligt, een grootte
waar iemand om kan geven.

## In RStudio: brms

De snelkoppeling hierboven behandelt één helling tegelijk en leent de standaardfout van
`lm()`. Het pakket **brms** past het hele model Bayesiaans aan, intercept, hellingen en
residuele SD samen, door simulatie (Markov chain Monte Carlo). Het breidt uit naar alles in
Deel 3: meerdere voorspellers, interacties, logistische regressie met `family = bernoulli()`,
en gemengde modellen met `(1 | id)`.

brms zet elk model om in een programma voor Stan en compileert het, wat een C++-compiler
vereist. Daarom draait het niet in de browser. Op je eigen computer:

```r
# Once: install.packages("brms"). Windows also needs Rtools,
# a Mac the Xcode command line tools.
library(brms)

fit <- brm(
  wellbeing ~ autonomy,
  data = d,
  prior = prior(normal(0, 0.5), class = b),
  seed = 1
)

summary(fit)                     # estimates with 95% credible intervals
hypothesis(fit, "autonomy > 0")  # the probability of a claim
pp_check(fit)                    # does the model reproduce the data?
```

Met deze prior en deze data zou brms een helling moeten geven van ongeveer de 0,89 die je hier
berekende, aangezien de normale snelkoppeling bij 480 gevallen zeer nauwkeurig is. Verwacht
geen exacte match: brms trekt steekproeven uit de posterior, dus zijn getallen verschillen een
beetje in de latere decimalen.
