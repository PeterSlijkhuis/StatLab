Elk interval en elke p-waarde in deze cursus beantwoordde tot nu toe één soort vraag: *als de
ware waarde dit was, hoe vaak zouden data zoals de mijne dan voorkomen?* Bayesiaanse statistiek
draait dat om. Ze vraagt: *gegeven de data die ik heb, hoe aannemelijk is elke mogelijke ware
waarde?*

Daarvoor is één extra ingrediënt nodig, waarvoor Les 8-2 je waarschuwde: een **prior**, een
uitspraak over hoe aannemelijk elke waarde was voordat je keek. De data werken de prior dan bij
tot een **posterior**. Deze hele module gaat over die ene stap, op drie manieren uitgevoerd.

## Eén onbekende: het vertrekpercentage

De HR-afdeling wil weten welk aandeel van de werknemers het bedrijf verlaat. Begin met alleen
de eerste 20 records.

<CodeBlock id="c-first20" code={`d <- read.csv("data/workplace.csv", stringsAsFactors = TRUE)

first20 <- d[1:20, ]
left20 <- sum(first20$left_company)
left20`} />

Drie van de twintig vertrokken. Het ware vertrekpercentage is een getal tussen 0 en 1, en de
data maken sommige waarden veel geloofwaardiger dan andere. Bayesiaanse schatting maakt dat
precies in vier stappen.

## Stap 1: som de kandidaten op

Neem een raster van kandidaatwaarden voor het percentage, van 0 tot 1 in kleine stappen. Elke
berekening hierna wordt één keer per kandidaat uitgevoerd.

<CodeBlock id="c-grid" code={`p_grid <- seq(0, 1, length.out = 1001)
head(p_grid)`} />

## Stap 2: de prior

Zeg, voordat je data ziet, hoe aannemelijk elke kandidaat is. De nederigste prior noemt ze
allemaal even aannemelijk: een vlakke lijn.

<CodeBlock id="c-prior" code={`prior <- rep(1, length(p_grid))`} />

## Stap 3: de likelihood

Hoe waarschijnlijk zijn de data, 3 vertrekkers op 20, voor elk kandidaatpercentage? Dat is een
binomiale kans, en `dbinom()` berekent haar voor het hele raster tegelijk.

<Predict
  id="p-likelihood-peak"
  question="Welk kandidaatpercentage maakt 3 vertrekkers op 20 het meest waarschijnlijk?"
  choices={[
    { text: '0,03', response: 'Bij 3% verwacht je minder dan één vertrekker op twintig, dus drie is ongewoon veel.' },
    { text: '0,15', correct: true, response: 'Ja: 3 op 20 is 0,15, en het percentage dat het best bij de data past is de waargenomen proportie zelf.' },

/>

<CodeBlock id="c-likelihood" code={`likelihood <- dbinom(left20, size = 20, prob = p_grid)
p_grid[which.max(likelihood)]`} />

De likelihood is **geen** kansverdeling voor het percentage. Ze zegt hoe goed elk percentage de
data voorspelde, en ze hoeft niet op 1 uit te komen.

## Stap 4: de posterior

Vermenigvuldig prior met likelihood, kandidaat voor kandidaat, en deel dan door het totaal zodat
het resultaat optelt tot 1. Dat is de regel van Bayes, en het resultaat is de **posterior**:
hoe aannemelijk elk percentage nu is, nu je de data hebt gezien.

<CodeBlock id="c-posterior" code={`posterior <- prior * likelihood
posterior <- posterior / sum(posterior)

plot(p_grid, posterior, type = "l",
     xlab = "Leaving rate", ylab = "Posterior probability")

# The single most plausible rate, and the average over the posterior.
p_grid[which.max(posterior)]
sum(p_grid * posterior)`} />

De piek ligt bij 0,15, de waargenomen proportie. Het posterior gemiddelde is iets hoger,
ongeveer 0,18, omdat de curve een lange rechterstaart heeft: met slechts twintig mensen bevatten
percentages van 30% of meer nog bijna 9% van de posterior.

## Meer data, smallere posterior

Gebruik nu alle 480 werknemers.

<CodeBlock id="c-all" code={`left_all <- sum(d$left_company)
n_all <- nrow(d)
c(left = left_all, employees = n_all)

posterior_all <- prior * dbinom(left_all, size = n_all, prob = p_grid)
posterior_all <- posterior_all / sum(posterior_all)

plot(p_grid, posterior_all, type = "l", col = "steelblue",
     xlab = "Leaving rate", ylab = "Posterior probability")
lines(p_grid, posterior, col = "grey50")

sum(p_grid * posterior_all)`} />

De blauwe curve is hoog en smal, rond 0,23. Met 480 mensen zijn de meeste percentages
onaannemelijk geworden. Die versmalling is wat een Bayesiaan bedoelt met leren van data, en ze
speelt de rol die een krimpende standaardfout in Module 7 speelde.

## Een prior die iets weet

Een vlakke prior is ook een keuze, en zelden de eerlijkste. Stel dat HR uit sectorrapporten weet
dat vertrekpercentages meestal rond 15% liggen. Een **bètaverdeling** kan dat zeggen:
`dbeta(p, 3, 17)` piekt bij 0,11, heeft haar gemiddelde bij 3 / (3 + 17) = 0,15, en bevat
ongeveer evenveel informatie als twintig werknemers.

<CodeBlock id="c-informed" code={`informed <- dbeta(p_grid, 3, 17)

post_small <- informed * dbinom(left20, size = 20, prob = p_grid)
post_small <- post_small / sum(post_small)

post_large <- informed * dbinom(left_all, size = n_all, prob = p_grid)
post_large <- post_large / sum(post_large)

c(first_20 = sum(p_grid * post_small), all_480 = sum(p_grid * post_large))`} />

Met twintig werknemers zijn de prior en de data ongeveer evenveel waard, en het posterior
gemiddelde komt uit op 0,15. Met 480 wegen de data vele malen zwaarder dan de prior, en het
posterior gemiddelde van 0,224 ligt dicht bij het antwoord met de vlakke prior. **Hoe meer data
je hebt, hoe minder de prior ertoe doet.** Met weinig data doet de prior er veel toe, en dat is
precies wanneer je moet zeggen welke je gebruikte en waarom.
