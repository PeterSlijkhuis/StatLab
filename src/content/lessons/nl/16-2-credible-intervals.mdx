Het raster van Les 16-1 werkt voor elke prior, maar voor een proportie is er een kortere weg.
Wanneer de prior een bètaverdeling is en de data aantallen successen zijn, is de posterior ook
een bètaverdeling, en kun je haar opschrijven zonder raster.

## De bètasnelkoppeling

Een `Beta(a, b)`-prior werkt als een voorsprong van `a` successen en `b` mislukkingen (dus
`a + b` is ruwweg hoeveel waarnemingen ze waard is). Voeg de nieuwe data toe en de posterior is
`Beta(a + successen, b + mislukkingen)`. De vlakke prior uit de vorige les is `Beta(1, 1)`: een
voorsprong van één succes en één mislukking.

<CodeBlock id="c-conjugate" code={`d <- read.csv("data/workplace.csv", stringsAsFactors = TRUE)

left_all <- sum(d$left_company)
stayed_all <- nrow(d) - left_all

p_grid <- seq(0, 1, length.out = 1001)
grid_post <- dbinom(left_all, size = nrow(d), prob = p_grid)
grid_post <- grid_post / sum(grid_post)

# The same posterior from the shortcut, scaled to the grid for comparison.
beta_post <- dbeta(p_grid, 1 + left_all, 1 + stayed_all)
beta_post <- beta_post / sum(beta_post)

max(abs(grid_post - beta_post))`} />

De twee komen op vele decimalen overeen. Vanaf nu beantwoorden `qbeta()`, `pbeta()` en
`rbeta()` vragen over de posterior rechtstreeks.

## Het geloofwaardigheidsinterval

De middelste 95% van de posterior is een **95%-geloofwaardigheidsinterval** (in het Engels
credible interval, 95% CrI). `qbeta()` geeft het 2,5e en 97,5e percentiel.

<CodeBlock id="c-credible" code={`credible <- qbeta(c(0.025, 0.975), 1 + left_all, 1 + stayed_all)
round(credible, 3)

# The frequentist 95% confidence interval, for comparison.
round(binom.test(left_all, nrow(d))$conf.int, 3)`} />

De getallen zijn bijna hetzelfde, 0,192 tot 0,267 tegenover 0,190 tot 0,267. Met een vlakke
prior en veel data zijn ze dat meestal. De **betekenis** is anders, en dat verschil is de reden
dat sommige onderzoekers de Bayesiaanse versie verkiezen:

- Het **geloofwaardigheidsinterval** zegt: gegeven deze data en deze prior is er een kans van
  95% dat het vertrekpercentage tussen 19,2% en 26,7% ligt.
- Het **betrouwbaarheidsinterval** zegt: dit interval komt uit een procedure die het ware
  percentage in 95% van de steekproeven vangt. Les 7-2 liet zien dat je op dit ene interval
  geen kans kunt zetten.

De zin die mensen over een betrouwbaarheidsinterval willen zeggen, is de zin die een
geloofwaardigheidsinterval werkelijk toestaat.

## Twee groepen vergelijken met simulatie

Trek voor twee groepen duizenden aannemelijke percentages uit elke posterior met `rbeta()`, en
vergelijk ze trekking voor trekking. Elk paar trekkingen is één aannemelijke toestand van de
wereld, dus het aandeel paren waarin het ene percentage lager is, is de kans dat het lager is.

<CodeBlock id="c-simulate" code={`left_trained <- sum(d$left_company[d$training == "Yes"])
n_trained <- sum(d$training == "Yes")
left_untrained <- sum(d$left_company[d$training == "No"])
n_untrained <- sum(d$training == "No")

set.seed(1502)
rate_trained <- rbeta(10000, 1 + left_trained, 1 + n_trained - left_trained)
rate_untrained <- rbeta(10000, 1 + left_untrained, 1 + n_untrained - left_untrained)

# Probability that training goes with a lower leaving rate.
mean(rate_trained < rate_untrained)

# A 95% credible interval for the difference in rates.
round(quantile(rate_trained - rate_untrained, c(0.025, 0.975)), 3)`} />

Een kans dicht bij een half, en een interval voor het verschil dat ongeveer 7 punten naar beide
kanten loopt. De data onderscheiden de twee groepen niet. Simulatie vervangt hier een formule,
en ze werkt voor elke grootheid die je uit de trekkingen kunt berekenen: een ratio, een
verschil, of beide percentages boven 20% liggen.
