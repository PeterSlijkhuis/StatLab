The rank tests of Lesson 12-4, Mann-Whitney and Kruskal-Wallis, assume every score
comes from a different person. When the same people are measured more than once, the ranks have to be
taken **within** each person, just as the mixed model removes each person's own
level. Two tests do this: the Wilcoxon signed-rank test for two measurements, and
the Friedman test for three or more.

<CodeBlock id="c-load" code={`library(dplyr)
library(tidyr)

d <- read.csv("data/workplace.csv", stringsAsFactors = TRUE)

d <- d %>% mutate(change = engagement_t2 - engagement_t1)

d %>% summarise(median_change = median(change), mean_change = mean(change), n = n())`} />

## Two measurements: the Wilcoxon signed-rank test

Take each employee's change, rank the changes by their size while ignoring the
sign, then add up the ranks of the positive changes. That sum is *V* (the textbook calls it *T*+). If nothing
changed on average, the positive and negative changes would carry about equal rank
sums, and *V* would be near half of the total.

<CodeBlock id="c-wilcoxon" code={`wilcox.test(d$engagement_t2, d$engagement_t1, paired = TRUE)

t.test(d$engagement_t2, d$engagement_t1, paired = TRUE)$statistic`} />

Both say engagement rose. The *t*-test asks about the mean change; the signed-rank
test asks whether positive changes outweigh negative ones in rank. The order of the
two columns matters: swap them and *V* becomes the rank sum of the **negative**
changes instead.

## Three or more measurements: the Friedman test

Back to the simulated pre, mid and post stress study from Lesson 14-4. The Friedman
test ranks the three scores **within** each person (1, 2 or 3), then asks whether
some waves collect higher ranks than others.

<CodeBlock id="c-waves" code={`set.seed(114)
n <- 60
id <- factor(1:n)
base <- rnorm(n, 30, 6)
wide <- data.frame(
  id,
  pre = round(base + rnorm(n, 0, 3), 1),
  mid = round(base - 3 + rnorm(n, 0, 3), 1),
  post = round(base - 5 + rnorm(n, 0, 3), 1)
)

waves <- wide %>%
  pivot_longer(cols = c(pre, mid, post), names_to = "wave", values_to = "stress") %>%
  mutate(wave = factor(wave, levels = c("pre", "mid", "post")))

friedman.test(stress ~ wave | id, data = waves)`} />

The formula reads "stress by wave, within id". Like *H*, the Friedman statistic is
compared with a chi-square distribution with *k* − 1 degrees of freedom. It needs
every person measured at every wave: anyone with a gap is dropped entirely, which is
the same limitation the paired *t*-test had and the mixed model does not.

<CodeBlock id="c-within-ranks" code={`waves %>%
  group_by(id) %>%
  mutate(rank_within = rank(stress)) %>%
  group_by(wave) %>%
  summarise(mean_rank = mean(rank_within))`} />

Most people have their highest stress at pre and their lowest at post, so the mean
rank falls from about 2.6 at pre to about 1.4 at post.
