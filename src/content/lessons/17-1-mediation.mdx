Trained employees perform a little better. A theory says why: training
raises engagement, and engaged people perform better. **Mediation analysis**
asks whether the data fit that story, by splitting the effect of training into
the part that runs through engagement and the part that does not.

<CodeBlock id="c-load" code={`d <- read.csv("data/workplace.csv", stringsAsFactors = TRUE)

total_model <- lm(performance ~ training, data = d)
coef(total_model)`} />

Trained employees perform about 1.6 points better. That is the **total effect**,
called *c*.

## Three regressions, five numbers

Besides the total effect, the mediation model needs two more regressions.

- The **a path**: does training predict the mediator, engagement?
- The **b path**: does engagement predict performance, with training held constant?

<CodeBlock id="c-paths" code={`path_a <- lm(engagement_t2 ~ training, data = d)
path_b <- lm(performance ~ engagement_t2 + training, data = d)

a <- coef(path_a)[["trainingYes"]]
b <- coef(path_b)[["engagement_t2"]]
direct <- coef(path_b)[["trainingYes"]]
total <- coef(total_model)[["trainingYes"]]

c(a = a, b = b, indirect = a * b, direct = direct, total = total)`} />

- **a** = 4.07: trained employees are about 4 points more engaged.
- **b** = 0.44: each point of engagement goes with 0.44 points of performance,
  among people with the same training status.
- The **indirect effect**, a × b = 1.78, is the part of training's effect that
  runs through engagement.
- The **direct effect**, *c′* = -0.16, is what is left.

For linear models fitted to the same rows, indirect plus direct is exactly the
total: 1.78 - 0.16 = 1.62. Here nearly all of the effect runs through
engagement.

## A bootstrap interval for the indirect effect

Resample employees with replacement, refit both paths, multiply, and repeat.
The middle 95% of the products is the interval.

<CodeBlock id="c-boot" code={`set.seed(171)
indirect_boot <- replicate(1000, {
  s <- d[sample(nrow(d), replace = TRUE), ]
  coef(lm(engagement_t2 ~ training, data = s))[["trainingYes"]] *
    coef(lm(performance ~ engagement_t2 + training, data = s))[["engagement_t2"]]
})

quantile(indirect_boot, c(0.025, 0.975))`} />

The interval, about [1.19, 2.40], excludes zero, so the indirect effect is
supported.

## What mediation can and cannot show

Mediation is a causal story, and the statistics cannot make it true.

- **Order in time.** The predictor should come before the mediator, and the
  mediator before the outcome. Engagement here was measured after training,
  which helps. Performance was not measured later still.
- **No hidden common cause.** If some third thing, such as a good manager, raised
  both engagement and performance, the b path would be inflated, and randomising
  training does not protect against that.
- **Consistent with, not proof of.** With data from one study, write that the
  pattern is consistent with mediation.

## In RStudio: lavaan

The `lavaan` package fits both paths as one model and bootstraps the indirect
effect for you. It needs numbers, so training becomes 0 and 1.

```r
library(lavaan)
d$trained <- as.numeric(d$training == "Yes")

model <- "
  engagement_t2 ~ a * trained
  performance ~ b * engagement_t2 + c * trained
  indirect := a * b
  total := c + a * b
"
set.seed(1)
fit <- sem(model, data = d, se = "bootstrap", bootstrap = 1000)
parameterEstimates(fit, boot.ci.type = "perc")
```

The `indirect` row gives the same a × b estimate with a bootstrap interval of its
own. Expect that interval to be close to, not identical with, the one above: it
comes from different resamples. The PROCESS
macro for SPSS, model 4, fits the same model.
